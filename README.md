# VCAM-Portugues-Camera-Virtual-Xposed
Câmera virtual Xposed (Vector, LSPosed e KernelSU) em português.  Funções: • Vídeos locais ou streams de rede (RTSP/RTMP). • Intercepta fotos para injetar vídeo. • Controle rápido na barra de notificações. • Áudio original, troca de áudio e Hook de microfone. • Reconexão automática e vídeo local de reserva.
